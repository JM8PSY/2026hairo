# モーター駆動の配線（ESP32 → PCA9685 → MD20A）

`firmware/motor_esp32/include/board_config.h` と必ず一致させること。
**ピン番号は仮**。配線が確定したら両方を更新する。

## ESP32（ESP32-DevKit）

| GPIO | 用途 | 備考 |
|------|------|------|
| 21 | I2C SDA | PCA9685 へ |
| 22 | I2C SCL | 400kHz |
| 25 | PCA9685 OE | **外付け 2.2kΩ で 3.3V へプルアップ**（ESP32 リセット中も全出力 Low） |
| 2 | 状態 LED | ARMED 点灯 / DISARMED 1Hz / ESTOP・FAULT 5Hz |
| 32 | ふた「開」リミット（親機） | NC スイッチを GND との間に。INPUT_PULLUP |
| 33 | ふた「閉」リミット（親機） | 同上 |

PCA9685 の VDD は 3.3V。複数枚の OE は同じ GPIO にまとめてよい。

## 親機（PCA9685 ×2）

| モーター | 役割 | PWM（0x40） | DIR（0x41） | 上限 | 加速 | 備考 |
|----------|------|-------------|-------------|------|------|------|
| P1 | メインクローラー左 | ch0 | ch0 | 100% | 2000/s | |
| P2 | メインクローラー右 | ch1 | ch1 | 100% | 2000/s | |
| P3 | サブクローラー左前 | ch2 | ch2 | 80% | 2000/s | |
| P4 | サブクローラー右前 | ch3 | ch3 | 80% | 2000/s | |
| P5 | サブクローラー左後 | ch4 | ch4 | 80% | 2000/s | |
| P6 | サブクローラー右後 | ch5 | ch5 | 80% | 2000/s | |
| P7 | ふた（正転=開） | ch6 | ch6 | 60% | 2000/s | 開/閉リミット、連続 5 秒で停止 |
| P8 | リール | ch7 | ch7 | 40% | 1000/s | |
| P9 | 未定 | ch8 | ch8 | 0 | — | 出力 0 固定 |

PCA9685 0x41 はアドレスジャンパ A0 をはんだでブリッジする。

## 子機（PCA9685 ×1、0x40）

| モーター | 役割 | PWM | DIR | 上限 | 加速 |
|----------|------|-----|-----|------|------|
| C1 | クローラー左 | ch0 | ch1 | 100% | 2000/s |
| C2 | クローラー右 | ch2 | ch3 | 100% | 2000/s |
| C3 | デブリ回収ブラシ | ch4 | ch5 | 80% | 2000/s |

## MD20A との接続

PCA9685 の PWM 出力 → MD20A の PWM、DIR 出力 → MD20A の DIR、GND 共通。
モーターの回転方向が逆なら、配線ではなく `board_config.h` の `invert` で直してよい（表も更新する）。
